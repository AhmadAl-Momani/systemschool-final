QuizzyMind is an Arabic web-based school management and online exam platform that brings administrators, teachers, students, and parents together in one system. Teachers can create online exams (multiple choice and true/false) with a set duration, schedule, and password, upload worksheets and track downloads, and review student results through charts and detailed answer breakdowns. Students can take exams, view their scores and answer details, and practice with random quizzes at different difficulty levels. The interface is fully Arabic (RTL) and mobile-friendly.

Tools and technologies used:

Backend: PHP (mysqli)
Database: MySQL / MariaDB
Frontend: HTML, CSS, JavaScript with Bootstrap 5 RTL
Libraries: jQuery (AJAX requests), Chart.js (charts), SweetAlert2 (alerts), animate.css (animations), Font Awesome (icons)
Font: Tajawal (Google Fonts)
Development environment: XAMPP# systemschool-final
